# Don't-Bore-Me Network
### In development...
Await updates.

## What is it?
I was bored at "Introduction to computer science" lesson. So I got an idea to build something big to combat the boredom.

The idea is to have a distributed network, which can discover other users and communicate with them. First thing that will be implemented is chat system and an ability to use the engine to create plugins and further expand the network functional diversity. It will not only be fun, but a nice way to practice coding skills that we could have learned instead of learning how to create a folder.
